# フットサル得点板 (FutsalScoreboard)

iPhone を簡易得点板として使うフットサル向けアプリ。個サル・エンジョイから大会まで、同じ画面で使える。

- 対象: iPhone のみ / iOS 17 以上 / 縦向き固定
- 技術: SwiftUI、通信なし・アカウントなし(端末内で完結)
- プロジェクト生成: [XcodeGen](https://github.com/yonaskolb/XcodeGen)(`project.yml` を編集したら `xcodegen generate`)

## 機能(MVP)

- 2 チームの得点(エリアをタップで +1、− ボタン)
- オールリセット(得点とタイマーをまとめて初期状態に戻す)
- チーム名・チーム色
- 試合時間の設定、開始・停止・リセット
- 残り時間の予告(予告音 + バイブ。タイミングは設定で変更でき、初期値は残り 1 分)と、終了時のブザー(約 3 秒)+ バイブ
- 前後半の区別はしない。前後半がある試合は、時間切れのあと「タイマーを戻す」で次を始める
- 画面スリープ防止

作らないもの: 前後半の管理、累積ファウル、タイムアウト、退場 2 分タイマー、後半の左右入れ替え、勝ち残り管理(保留)

## 画面構成

1. **スコアボード**(起動時に直接開く。前回の設定を引き継ぐ)
2. **試合設定シート**(歯車から開く)

### スコアボード

```
┌─────────────────────────┐
│ ⚙               [リセット] │
│      ┌───────────┐      │
│      │  07:00   │      │
│      └───────────┘      │
│   チームA  │  チームB   │
│ (青の背景)│(赤の背景) │
│     3     │     2      │
│            │            │
│ [−]  [ ▶ 開始 ]   [−]  │
└─────────────────────────┘
```

| 要素 | 操作 | 仕様 |
|---|---|---|
| 得点エリア(画面の左半分・右半分) | タップ | +1。背景はチーム色。0.3 秒以内の連打は無視 |
| − ボタン | タップ | −1。0 未満にはならない |
| リセット | タップ | オールリセット。確認ダイアログのあと、得点 0-0・タイマー満タンに戻す |
| タイマー | タップ(止まっているときだけ) | 分・秒のホイールで時間を変える。未開始なら試合時間そのものを変え、途中なら今の残り時間だけ変える。MM:SS のカウントダウンで、予告のタイミングを切ったら文字をオレンジに |
| 開始・停止 | タップ | 開始と停止を切り替える。画面で一番大きなボタン |
| 開始ボタン長押し | メニュー | 「タイマーだけ戻す」。確認ダイアログあり |
| ⚙ 設定 | タップ | 設定シートを開く。タイマー動作中は無効 |

### 状態遷移

```
準備中 ──開始──▶ 進行中 ◀──開始/停止──▶ 停止中
                    │
                 0:00 になる
                    ▼
                 時間切れ ──▶ [タイマーを戻す] → 準備中(得点は維持)
                          └─▶ [新しい試合]   → 準備中(0-0)
```

- 時間切れ: ブザー約 3 秒 + バイブ。開始ボタンの位置に次の操作ボタンを出す。得点は表示したまま
- タイマーを戻す: 得点はそのままで、タイマーを試合時間に戻す(後半を始めるときなど)
- 新しい試合: 得点 0-0、タイマーを試合時間に戻す。チーム名と色は維持

### 試合設定シート

| 項目 | 仕様 |
|---|---|
| 試合時間 | 1 秒〜40 分、分・秒のホイールで秒単位に設定。初期値 7 分。よく変えるので一番上に置く |
| 残り時間の予告 | なし / 半分 / 10秒 / 15秒 / 30秒 / 45秒 / 1分 / 1分30秒 / 2分 / 3分 / 5分 から選ぶ。「半分」は試合時間の半分が過ぎたとき(7 分なら残り 3 分 30 秒)で、試合時間を変えると追従する。初期値は 1 分。次に開始したときから反映 |
| チーム名 | 最大 8 文字。初期値「チームA」「チームB」 |
| チーム色 | 赤・青・黄・緑・オレンジ・白・黒・ピンクの 8 色。初期値は青と赤。黄と白は文字を黒にする |

試合時間の変更は、タイマー未開始ならすぐ反映、途中なら次にタイマーを戻したときから反映する。

## タイマーの仕組み

- 開始時に「終了予定時刻 = 今 + 残り時間」を記録し、表示はその差から毎回計算する。バックグラウンドや着信でもずれない
- 開始時に「予告」と「終了」のローカル通知を予約し、停止したら取り消す。通知の許可は最初の開始時に求める
- 予告のタイミング以下の残り時間から開始した場合、予告は鳴らさない
- 予告音と終了音は別の音にする
- オーディオセッションを再生用にして、マナーモードでもブザーを鳴らす
- スコアボード表示中は画面をスリープさせない
- 0:00 で止める(延長のカウントアップはしない)
- ブザー音は音源ファイルを同梱せず、起動時にコードで WAV を生成する(`ToneGenerator`)。すべてオリジナルの音
  - 予告: ド・ミ・ソ・ドを駆け上がるベル(約 0.9 秒)
  - 終了: 駆け上がりを 2 回のあと、和音が響いて消える(約 3 秒)

### 制約

- アプリをバックグラウンドに回したときのブザーはローカル通知で鳴らす。通知音は iOS の仕様でマナーモードに従うため、マナーモード中は鳴らずバイブのみになる。確実に鳴らしたい場合は得点板を表示したままにする

## 開発

```bash
xcodegen generate
open FutsalScoreboard.xcodeproj
```

試合ロジック(`Match`)は時刻を引数で受け取る純粋な構造体にしてあり、`FutsalScoreboardTests` でテストしている。

## データモデル

```swift
struct TeamConfig { var name: String; var color: TeamColor }
struct MatchSettings { var home, away: TeamConfig; var periodSeconds: Int }  // 旧データの periodMinutes も読める

enum Clock {
  case ready(remaining: TimeInterval)
  case running(endDate: Date)
  case paused(remaining: TimeInterval)
  case expired
}
struct MatchState {
  var homeScore, awayScore: Int     // 0...99
  var clock: Clock
}
```

設定と試合状態は変更のたびに端末へ保存し、アプリが強制終了されても得点と残り時間を復元する。

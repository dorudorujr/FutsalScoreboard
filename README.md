# フットサル得点板 (FutsalScoreboard)

iPhone を簡易得点板として使うフットサル向けアプリ。個サル・エンジョイから大会まで、同じ画面で使える。

- 対象: iPhone のみ / iOS 17 以上 / 横向き固定
- 技術: SwiftUI、通信なし・アカウントなし(端末内で完結)
- プロジェクト生成: [XcodeGen](https://github.com/yonaskolb/XcodeGen)(`project.yml` を編集したら `xcodegen generate`)

## 機能(MVP)

- 2 チームの得点(エリアをタップで +1、− ボタン、Undo)
- チーム名・チーム色
- 試合時間の設定、開始・停止・リセット
- 残り 1 分の予告(短いブザー + バイブ)と、終了時のブザー(約 3 秒)+ バイブ
- 前半・後半の切り替え(個サルは前半だけ使う)
- 画面スリープ防止

作らないもの: 累積ファウル、タイムアウト、退場 2 分タイマー、後半の左右入れ替え、勝ち残り管理(保留)

## 画面構成

1. **スコアボード**(起動時に直接開く。前回の設定を引き継ぐ)
2. **試合設定シート**(歯車から開く)

### スコアボード

```
┌──────────────────────────────────────────────┐
│ ⚙                    前半                 ↶  │
│                     07:00                    │
│   チームA                          チームB    │
│  (青の背景)                     (赤の背景)  │
│       3                              2       │
│                                              │
│     [ − ]          [ ▶ 開始 ]        [ − ]   │
└──────────────────────────────────────────────┘
```

| 要素 | 操作 | 仕様 |
|---|---|---|
| 得点エリア(左右半分) | タップ | +1。背景はチーム色。0.3 秒以内の連打は無視 |
| − ボタン | タップ | −1。0 未満にはならない |
| ↶ Undo | タップ | 直前の得点操作(±1)を取り消す。何回でも戻せる。タイマー操作は対象外 |
| タイマー | 表示 | MM:SS のカウントダウン。残り 1 分未満で文字をオレンジに |
| 開始・停止 | タップ | 開始と停止を切り替える。画面で一番大きなボタン |
| リセット | 長押しメニュー | 「タイマーだけ戻す」「新しい試合」。どちらも確認ダイアログあり |
| ⚙ 設定 | タップ | 設定シートを開く。タイマー動作中は無効 |

### 状態遷移

```
準備中 ──開始──▶ 進行中 ◀──開始/停止──▶ 停止中
                    │
                 0:00 になる
                    ▼
                 時間切れ ─(前半なら)─▶ [後半へ]    → 後半の準備中(得点は維持)
                          └──────────▶ [新しい試合] → 前半の準備中(0-0)
```

- 時間切れ: ブザー約 3 秒 + バイブ。開始ボタンの位置に次の操作ボタンを出す。得点は表示したまま
- 前半終了時は [後半へ] と [新しい試合]、後半終了時は [新しい試合] のみ
- 新しい試合: 得点 0-0、前半に戻る。チーム名と色は維持

### 試合設定シート

| 項目 | 仕様 |
|---|---|
| チーム名 | 最大 8 文字。初期値「チームA」「チームB」 |
| チーム色 | 赤・青・黄・緑・オレンジ・白・黒・ピンクの 8 色。初期値は青と赤 |
| 試合時間 | 1〜40 分、1 分刻み(1 ハーフあたり)。初期値 7 分 |

試合時間の変更は、タイマー未開始ならすぐ反映、途中なら次の前半・後半から反映する。

## タイマーの仕組み

- 開始時に「終了予定時刻 = 今 + 残り時間」を記録し、表示はその差から毎回計算する。バックグラウンドや着信でもずれない
- 開始時に「残り 1 分」と「終了」のローカル通知を予約し、停止したら取り消す。通知の許可は最初の開始時に求める
- 残り 1 分以下から開始した場合、予告は鳴らさない
- 予告音と終了音は別の音にする
- オーディオセッションを再生用にして、マナーモードでもブザーを鳴らす
- スコアボード表示中は画面をスリープさせない
- 0:00 で止める(延長のカウントアップはしない)

## データモデル

```swift
struct TeamConfig { var name: String; var color: TeamColor }
struct MatchSettings { var home, away: TeamConfig; var periodMinutes: Int }

enum Period { case first, second }
enum Clock {
  case ready(remaining: TimeInterval)
  case running(endDate: Date)
  case paused(remaining: TimeInterval)
  case expired
}
struct MatchState {
  var homeScore, awayScore: Int     // 0...99
  var period: Period
  var clock: Clock
  var undoStack: [ScoreOp]          // (team, ±1)
}
```

設定と試合状態は変更のたびに端末へ保存し、アプリが強制終了されても得点と残り時間を復元する。
